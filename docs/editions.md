# Editions

tlansclaib is one app with two editions. Free is this repository, open source
under MIT. Pro is a private module, planned for app version 1.0. The official
installer will contain it, locked, and a licence key unlocks it in place,
offline. Building this repository gives the free app.

## The line

Free covers everything one person needs to transcribe one recording well: read
it, play it, correct it and export it in the standard formats. Anything that
makes results better, faster or safer is free as well.

Pro saves time for people who process many recordings or hand results on to
others: documents, automation, adapting to a field, local language models, and
rolling the app out in an organisation.

What is free stays free. A feature that shipped in the free app never moves to
Pro.

| Free | Pro |
|---|---|
| Transcription with every listed model and any model file | Word, Markdown and PDF export with speakers and timecodes |
| New models and languages | A batch queue and watched folders |
| Speed, such as the CoreML encoder | Custom vocabulary for names and terms |
| Speaker detection, also within one track | Translation, by Whisper or a local language model |
| Editor, player, search, history, transcribing again | Summaries, minutes and questions to a transcript, with a local language model |
| Text, SRT and WebVTT export | An installer with preset models and settings for organisations |
| Converting a Hugging Face model, a remote model list | |

## In this repository

Pro features are not built here. A new feature that falls on the Pro side of the
line, listed or not, is a question for the maintainer before any code.
